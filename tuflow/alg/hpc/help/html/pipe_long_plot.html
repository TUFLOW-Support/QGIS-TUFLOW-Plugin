Generates a pipe long plot with labelled pipe sizes, chainages, slopes, and optional DEM. See the TUFLOW plugin changelog for an example of the output: docs.tuflow.com/qgis-tuflow-plugin/changelog/2026.1.0

Included on the plot

  1. Pipes
  2. DEM (optional)
  3. Water level
  4. Energy line (optional)
  5. Pipe IDs
  6. Pipe sizes (currently only circular pipes are supported)
  7. Pipe slopes
  8. Chainages to start and end of pipes
  9. Pits

Advanced parameters

The advanced settings offer plot label and colour customisation.
